# A workspace with no Bot computer

Open this page: [{{ui:settings:shell.page.computer.name}}](/settings/computer)

This workspace has no Bot computer. Bots work with chat, memory, schedules, web search and fetch, and connected services. Features that need a Bot computer are hidden: the browser, the terminal, files on the Bot computer, and the Bot computer widget.

To add one, follow the options on the Bot computer page. The built-in VM needs a server with KVM. Do not tell a person that a Bot used a Bot computer when this page applies.
