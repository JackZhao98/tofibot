# A workspace with no computer

Open this page: [{{ui:settings:shell.page.computer.name}}](/settings/computer)

This workspace has no computer. Bots work with chat, memory, schedules, web search and fetch, and connected services. Features that need a computer are hidden: the browser, the terminal, files on a computer, and the computer widget.

To add one, follow the options on the Computer page. A computer needs a server with KVM. Do not tell a person that a Bot used a computer when this page applies.
