# schedule_kind_invalid

Open this page: [Where to look](/b/{bot}?side=tasks)

**Meaning.** The kind of the schedule is not one the server knows.

**Usual cause.** The kind is misspelled or comes from another version.

**Steps.**
1. Use one of: once, interval, daily, weekly.
2. Create or edit the schedule again.
