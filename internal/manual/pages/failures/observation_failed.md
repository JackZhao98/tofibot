# observation_failed

Open this page: [Where to look](/)

**Meaning.** A read-only step failed. Nothing was changed.

**Usual cause.** The source did not answer, or the request was refused.

**Steps.**
1. Use the evidence that you already have.
2. Finish the work and say which source did not answer.
3. Try the read again only if the task needs it.
