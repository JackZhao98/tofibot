# api_disabled

Open this page: [Where to look](/settings/connections)

**Meaning.** A Google API that the connection needs is not enabled in the Google project.

**Usual cause.** Google answered that the API is off.

**Steps.**
1. Open the connection. Press Enable. The button opens the Google page for that API.
2. Wait a minute, then check the connection again.
