# rollback_failed

Open this page: [Where to look](/settings/advanced#version)

**Meaning.** The update failed and the rollback needs attention.

**Usual cause.** The server could not return to the old version by itself.

**Steps.**
1. Run `sudo tofi status` on the server and follow its steps.
