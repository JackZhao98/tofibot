# folder_not_granted

Open this page: [Environments](/settings/computer#environment)

**Meaning.** The Bot has no grant for this folder on this Mac, so nothing was done.

**Usual cause.** The folder was never added for this Bot, or the person removed it.

**Steps.**
Work only in the folders the run context lists. To use another folder, ask the person to add it for this Bot in the Tofi Mac app: Settings > Environments > Folders on this Mac. Do not retry with another spelling of the same path.
