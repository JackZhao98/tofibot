# mcp_review_setup_missing

Open this page: [Where to look](/settings/connections)

**Meaning.** The setup of the tool is incomplete, so the call cannot be reviewed.

**Usual cause.** The schema of the tool is missing or incomplete.

**Steps.**
1. Call search_mcp_tools to read the schema again.
2. If the schema is still missing, tell the person to check the connection.
