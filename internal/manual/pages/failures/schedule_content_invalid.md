# schedule_content_invalid

Open this page: [Where to look](/b/{bot}?side=tasks)

**Meaning.** The task text is empty or too long.

**Usual cause.** The schedule has no instruction, or the instruction passed the limit.

**Steps.**
1. Write a short, complete instruction for the Bot that will run it.
