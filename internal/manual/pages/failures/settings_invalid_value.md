# settings_invalid_value

Open this page: [Where to look](/settings/general)

**Meaning.** The value does not fit the key.

**Usual cause.** The type, the range or the allowed values are wrong.

**Steps.**
1. Read the key with get to see its kind and options.
2. Call set again with a valid value.
