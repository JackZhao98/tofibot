# mcp_timeout

Open this page: [Where to look](/settings/connections)

**Meaning.** A read-only call timed out. Nothing was changed.

**Usual cause.** The server was slow or did not answer.

**Steps.**
1. Try again with a smaller request.
2. If it still fails, tell the person.
