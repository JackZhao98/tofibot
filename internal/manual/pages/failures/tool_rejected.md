# tool_rejected

Open this page: [Where to look](/)

**Meaning.** The tool refused the call before it changed anything.

**Usual cause.** A rule of the tool did not hold for this call.

**Steps.**
1. Read the reason in the message.
2. Change the arguments or the order of steps.
3. Send the call again. If the rule cannot hold, tell the person.
