# conversation_not_user_visible

Open this page: [Where to look](/)

**Meaning.** No person can see this conversation, so a question or approval card here would never be answered.

**Usual cause.** The run works in a Bot-to-Bot trace.

**Steps.**
1. Do not ask again.
2. Say in the reply what the person needs to decide. The reply goes back to the Bot that assigned the work.
