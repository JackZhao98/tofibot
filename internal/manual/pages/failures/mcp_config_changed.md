# mcp_config_changed

Open this page: [Where to look](/settings/connections)

**Meaning.** The configuration of the connection changed. The call needs a fresh review.

**Usual cause.** A person or a Bot edited the connection after the call was prepared.

**Steps.**
1. Search for the tool again with search_mcp_tools.
2. Send the call again.
