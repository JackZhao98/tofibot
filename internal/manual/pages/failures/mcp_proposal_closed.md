# mcp_proposal_closed

Open this page: [Where to look](/)

**Meaning.** The proposal ended. It cannot run or resume.

**Usual cause.** The person cancelled it, or the task that made it is no longer active.

**Steps.**
1. Make a new call if the work is still needed.
2. Do not use the old approval.
