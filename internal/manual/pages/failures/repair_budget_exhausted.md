# repair_budget_exhausted

Open this page: [Where to look](/)

**Meaning.** The tool reached its limit of repair attempts in this run. The tool stays closed for the rest of the run.

**Usual cause.** The same tool failed argument checks several times.

**Steps.**
1. Use another tool of the same server or another permitted route.
2. Tell the person what the tool could not do.
3. The limit starts again in the next run.
