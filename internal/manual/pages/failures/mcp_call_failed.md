# mcp_call_failed

Open this page: [Where to look](/settings/connections)

**Meaning.** A read-only call failed. Nothing was changed.

**Usual cause.** The server refused the request, or the retry limit ended.

**Steps.**
1. Read the message of the server.
2. Change the arguments if the message points to them.
3. Otherwise tell the person that the server cannot do this now.
