# mcp_host_unverified

Open this page: [Where to look](/settings/connections)

**Meaning.** The address of the connection could not be checked, so nothing was changed.

**Usual cause.** The name did not resolve, or the address has an odd form.

**Steps.**
1. Check the address.
2. Try again, or ask the person to add it on the Connections page.
