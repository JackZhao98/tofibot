# runs_still_active

Open this page: [Where to look](/settings/advanced#version)

**Meaning.** Bots were still running after an hour, so the update did not start.

**Usual cause.** Long runs or a stuck run.

**Steps.**
1. Stop the runs you do not need, or wait for them.
2. Try the update again.
