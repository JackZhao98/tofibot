# mcp_high_risk_unattended

Open this page: [Where to look](/settings/connections)

**Meaning.** The owner set this tool to always ask a person, and nobody attends this scheduled run. The call was not sent.

**Usual cause.** The tool has the mark Always asks me.

**Steps.**
1. Finish the other work of the run.
2. In the summary, name the connection, the tool and the step that waits.
3. The owner can set the tool to Asks when unsure on the page of the connection. Then the owner can choose Always allow on an approval card.
