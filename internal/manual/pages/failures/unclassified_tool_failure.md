# unclassified_tool_failure

Open this page: [Where to look](/)

**Meaning.** A tool failed and the system cannot tell if it changed anything.

**Usual cause.** The tool ended with an error that has no known class.

**Steps.**
1. Check the target state before you try again.
2. Do not repeat a write without that check.
3. Tell the person if you cannot check.
