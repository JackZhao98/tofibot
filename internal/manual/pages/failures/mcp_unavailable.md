# mcp_unavailable

Open this page: [Where to look](/settings/connections)

**Meaning.** The connection did not answer. The call was not sent.

**Usual cause.** The server is down or the network failed.

**Steps.**
1. Try again later.
2. Use another permitted method.
3. In a scheduled run, report the connection as unreachable.
