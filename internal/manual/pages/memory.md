# Memory

Open this page: [{{ui:work:memory.title}}](/b/{bot}?side=memory)

A Bot keeps notes between chats. Each note has a title, a description and a text. The Bot reads the notes that matter at the start of a run.

- A Bot has its own memory. A group has a shared memory that every member can read.
- A person reads and edits the notes in the Memory view of the sidebar.
- A Bot changes its notes with the memory tools: `list_memory`, `save_memory`, `update_memory` and `delete_memory`. The settings tool lists memory as a collection and does not change it.

Memory is not a secret store. Do not put passwords or keys in a note. A secret goes in through a private input card or on the Bot's Secrets page.

Exports of a Bot carry its memory only when a person exports the data. A share file of a Bot has no memory.
