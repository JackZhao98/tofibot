# Pause and resume a connection

Open this page: [{{ui:settings:shell.page.connections.name}}](/settings/connections)

A paused connection is not listed, searched or called in any run. Its configuration, sign-in, tool marks and standing allowances stay. Resuming needs no new approval, because the configuration did not change.

A Bot can pause or resume a connection with the settings tool (`connection.enabled`). The change is applied at once and can be undone from the chat line or from the Maintenance page.

Use pause when a service misbehaves or when you want Bots to stop using it for a while. Use disconnect to remove the sign-in.
