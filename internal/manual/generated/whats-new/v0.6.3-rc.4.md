# TOFI v0.6.3-rc.4

Environments, and cloud computers from E2B.

## New

- Settings › Environments replaces Computer and Other devices. It lists every place your Bots can work: the Bot computer on this server, an E2B cloud computer, and your paired Macs, each with its status and which Bots can use it. Add environment adds an E2B cloud computer or a Mac.
- E2B cloud computer: paste an E2B API key and TOFI sets up a cloud computer in your own E2B team. It runs the same Bot computer as the server (desktop, browser, terminal, files), pauses after 15 idle minutes and resumes when a Bot needs it. E2B bills your account while it runs. If you also have a computer on the server, you choose which one your Bots use.
- Bot settings › Tools lists the environments the Bot can use.

## Changes

- Keys and variables moved to the Advanced group. The Bot computer's size controls are behind Configure.
- Detailed Mac settings stay in the desktop app; on the web you see your Macs and can disconnect them.
