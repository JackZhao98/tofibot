# TOFI v0.6.3-rc.19

A live step list above the message box, sign-in over plain http, and fixes for backups, file storage and Safari.

## Conversation

- **Step list while a Bot works.** When a Bot works on a request with several steps, a small card above the message box lists the steps. It marks the step in progress and the steps that are done, and it updates live. When the run ends, the list goes into the run's Activity. A retry or a resumed run continues the same list. To turn it off, go to Settings > System > Behavior > "Step list while a Bot works".
- **No twitch in Safari.** When older content loads above the newest message, the newest message stays still. Before, the conversation moved for a moment after it opened.
- **The cat loads once.** Versioned brand images are cached, so the cat does not load again on each page.

## Sign-in

- **Sign-in over plain http.** On a server that also accepts http on the local network, sign-in over http no longer goes back to the sign-in page when the browser already has an https session. Sessions made before this change stay valid.

## Backups

- **Backup actions wait for the Recovery Key.** On the Backups card, Run, Verify and Show snapshots become available after you confirm the Recovery Key.
- **Not set up is not an error.** When off-site backup is not set up, `tofi backups` and the Backups card say so. Before, they showed a storage error.
- **Single-account restore waits for runs.** `tofi restore --account <id>` waits until the account's runs end. It does not stop them.
- **Backup alerts.** The check for old backups no longer changes the status while a backup job runs.

## File storage

- **Move files from a key that cannot list the bucket.** A move from an earlier bucket now starts when that bucket's key cannot list objects. A key that the bucket refuses gets a clear message.
- **Reconcile report.** The count of deleted files no longer includes TOFI's own test objects.
