# TOFI v0.6.3-rc.43

The last pages move onto the new design, and the old styles are gone.

## Bot settings

- **Six sections.** Bot settings are grouped into six sections.
- **Tool tiers per Bot.** Each Bot has its own tool tiers and Skills.

## Tasks, artifacts and the Bot computer

- **Tasks board** uses the new toolbar, kind control and create buttons.
- **Artifacts** cover and widget use the new cards and file rows.
- **Bot computer and Mac Bot browser** use the new screen panel.
- **Mac Bot-browser tabs** use the new compact tabs.

## First run

- **Onboarding** uses the new cards and fields.

## Under the hood

- **Old design styles removed.** Dead rules and the old spring helper are gone; the mail flight animation looks the same.
