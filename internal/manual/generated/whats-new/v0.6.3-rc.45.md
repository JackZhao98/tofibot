# TOFI v0.6.3-rc.45

The last old design rules are gone, and a few display bugs are fixed.

## Fixes

- **A menu opened while its code loads** no longer stays blank.
- **Block code in a message bubble** keeps the terminal plate. The inline code style no longer reaches it.
- **Fixes from the full UI check and the 2x look** are applied across the app.

## Design

- **Buttons** use the new kit Button everywhere.
- **The note under a control and its error** use the new Note.
- **The connect and paste-back dialogs** use the new Dialog.

## Under the hood

- **Old design style files removed** (the V2 app, foundations and interaction rules).
- **UI tests are more stable.** The sidebar pin test judges CPU cost, not frame times. Test Vite servers keep their own cache.
