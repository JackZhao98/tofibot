# TOFI v0.6.3-rc.13

The Bot uses the computer that fits where you write from, and says which one it used. Menus, popups and other controls now come from standard libraries, with one motion for every popup.

## Changed

- **Environments follow where you write from.** From the web or your phone, the Bot uses the Bot computer first. From the Mac app, it uses that Mac first: the Tofi app's built-in browser, then Safari or Chrome through desktop control, then the Bot computer. When one is not available, the Bot goes on to the next one without asking. Each browser and desktop step names the computer and browser that ran it. If you name a computer, the Bot uses that one.
  - Settings › Environments shows each feature of a computer (built-in browser, desktop control, files, commands) as Connected, Disconnected or Off.
  - New settings there: **Preferred environment (web and mobile)**, **Preferred environment (Mac app)** and **Automatic environment failover**.
  - The Mac app sends where a message comes from only from version 0.2.6. Older Mac apps count as the web.
- **Mac app: the Bot browser opens in a panel on the right of the main window,** and the Bot computer is a card in the widget column. You can browse in the panel at any time; take over and give back in place.
- **One motion for menus and popups.** Every menu, popover and list grows from the control you pressed, on the same curve. Menus open when you press, not when you release.
- **Standard controls.** Tabs, segmented choices, switches, folding sections, the message actions bar, the search palette and the @ list use Radix and cmdk. Arrow keys now move between tabs and between choices. Widgets and Web tool sources reorder with dnd-kit; the small computer window drags and snaps with Motion. Settings file drops use react-dropzone.
- **Mac app pages from the Web UI** (Mac app 0.2.6): the first-run setup, update required, local run and permission guide pages, now in seven languages.
- **Admin › Design system:** admins can open the catalog of every interface component.

## Fixes

- The Bot said it had used the Mac's built-in browser when it had used the Bot computer. Results now name the computer, so this cannot happen silently.
- The first open of the account menu took about 0.3 seconds. It now opens on the press.
- On the Mac, a dark band showed beside the sidebar. It is gone.
- The version card in Settings › Advanced no longer fails for a release without a notes link.
- The @ list in the Mac app sits at the cursor, as on the web.
