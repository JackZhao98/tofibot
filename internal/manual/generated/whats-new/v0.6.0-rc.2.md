# TOFI v0.6.0-rc.2

Changes since v0.6.0-rc.1. This is a release candidate.

## Bots and settings

- A Bot can read and change settings for you: its own profile, other Bots, your preferences, conversations and connections.
- Changes to another Bot, to permissions or to connections show a confirmation card first. Other changes show a notice with Undo.
- Scheduled and other unattended runs can read settings but cannot change them.
- A Bot can look up the product manual and send you a link that opens the right Settings page.
- Bot looks and the theme are stored on the server, so they follow you to other devices.

## Computer

- A Bot works without a computer. An admin can attach or detach the computer while TOFI runs.
- The admin sets the size of each computer. Members can see the size but not change it.
- Computers have a lock per computer, given to one Bot at a time for each tool call.

## Security

- Each account's tools run in their own network, process limits, memory limits and disk quota.
- Tool processes run without privileges and with a system-call filter.

## Updates and data

- TOFI refuses to start on a database that a newer version wrote, and tells you how to update or restore.
- A model without a known context window now assumes 500,000 tokens.

## Interface

- The Settings navigation keeps a thin scrollbar and does not squeeze its labels.
- The working dot on a pinned tile sits inside the tile.
