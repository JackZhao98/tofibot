# TOFI v0.6.0-rc.1

Changes since v0.2.2-rc.3. This is a release candidate.

## Settings

- Settings has a new layout. Pages that few people use are in a folded Advanced group.
- Permissions is one control: Auto or Ask.
- Search & fetch and Behavior are separate pages.
- General has a Chats section. It holds Show activity and two notification switches: one for chat replies and one for task results.
- The language list starts with your browser language, marked Default.
- The Theme choices have short names.
- Each model provider has its own card.
- A Claude key now starts with a smaller, faster default model.
- The Computer resources sheet, the export groups and the accounts list have a new design.
- All drop-down lists look and work the same way.
- The account menu has links to the most used pages and opens faster.

## Chat

- The activity of a run is one timeline in time order. A message, a ticket or a note between two tool calls splits it into blocks.
- A folded tool row shows how many calls it holds.
- Retry on a failed run shows "Retrying..." until the server starts the new run. A refusal shows its reason next to the button. A failed run that has a retry folds to one line.

## Review

- When a Bot calls an outside tool, a schedule counts as a standing request of the Bot it targets.

## Look

- The sidebar shows the new calico logo.
