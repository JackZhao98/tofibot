# TOFI v0.6.1-rc.3

Changes since v0.6.1-rc.2. This is a release candidate.

## Browser and desktop

- The Browser engine now defaults to Playwright. In a live test it needed about 4 steps and 30 seconds for tasks that took Classic about 19 steps and 107 seconds. A workspace that never set the item uses the new default. A workspace that chose Classic keeps it.
- If the Playwright engine cannot start, or Chrome cannot be reached, the Bot uses the Classic browser and says so once. Settings shows a "Default changed" note on the Browser engine row.
- The Desktop engine default stays Classic.
- With the Accessibility engine, the screenshot and coordinate tools stay available. The Bot uses the control tree first and coordinates only when the tree is not enough.
- The control tree now shows if a check box, toggle or radio button is checked, unchecked or mixed.
- Large control trees are shortened to stay well under 25 KB. Hidden and decorative controls are left out. Long lists show "N more".
