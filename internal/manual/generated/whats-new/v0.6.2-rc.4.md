# TOFI v0.6.2-rc.4

## Naming

- The computer that a Bot uses is now called Bot computer everywhere: in the web app, in what Bots read, in the manual, in the docs and in the `tofi status` and `tofi computers` output. Today's kind of Bot computer is the built-in virtual machine (shown as "Built-in VM"). Commands, settings and API names do not change.

## Security audit

- After an update, `tofi security audit` no longer warns that hibernated Bot computers hold snapshots from the older Guest. This is expected: such a snapshot is never restored, and the Bot computer starts on the new Guest at its next use.
