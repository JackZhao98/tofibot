# TOFI v0.6.3-rc.36

Settings › Environments is now Devices, and the approval and question cards use the new design.

## Devices

- **Environments is now Devices.** The page has two sections: Bot computer and My devices.
- **One Bot computer.** The page shows the computer Bots use. A second computer that is ready shows as one line with Switch and Remove.
- **Switching moves your files.** Switching between the built-in VM and E2B moves the home folder to the new computer. Installed software and browser sign-ins do not move. If the move fails, the current computer stays.
- **One way to add.** With no Bot computer, the page offers Built-in VM (Set up or Attach) and E2B cloud computer (Add).
- **Each Mac has its own page.** Remote control, Blocked Bots, folders and the browser are on the Mac's page, with Disconnect at the bottom.

## Chat

- **Approval cards** have the new look: a bold edge while they wait, server-checked facts in a block, and one stamp once decided.
- **Questions, takeover and connection requests** use the same card.

## Fixes

- **Run order.** A scheduled run could start before a delegated one when both waited for the same Bot. The order is now kept.
