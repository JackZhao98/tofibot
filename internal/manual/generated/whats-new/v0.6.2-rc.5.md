# TOFI v0.6.2-rc.5

This release fixes tools that failed in ways a Bot could not recover from. A Bot could have the right tool and still report that it "cannot" do a task. An audit of every tool, based on one month of live tool calls, found these problems.

## Tool errors a Bot can act on

- When a tool's arguments are wrong, the error now names the problem: the missing field, the unexpected field, the wrong type or the value that is not allowed. Before, every tool said only that the arguments did not match.
- A large input schema from an external (MCP) tool now reaches the Bot whole. The top-level fields come first; only descriptions and sub-definitions are left out when it is too large. Before, a large schema was left out of search, and the hint was cut so that the fields the Bot needed were missing.
- TOFI's own checks ("show the schema first", "look at the screen first") no longer use up a Bot's repair attempts, and a successful call resets them. When the attempts do run out, the Bot is told the last problem and that its other tools still work.
- The error text of an external tool comes first and is marked as untrusted. A protocol rejection says that nothing was executed.
- Web search and page reading say which sources were tried, which were skipped and why, the HTTP status of a blocked page, and what to do next.
- Refusals for a connection that needs sign-in, approval or a person now name the connection, its state and where to fix it. `list_mcp_servers` shows each connection's state. The manual has a page for each failure code.

## Results that are not cut silently

- A result that is too long says what was left out and how to get the rest.
- Paging (offset and next offset) for reading files, web pages, skills, attachments, chat history, schedules and work items. Chat history search shows the newest results first.

## Bot computer and browser

- A slow browser or a lost connection is retried and no longer locks the tool. An action whose effect is unknown tells the Bot to check the result before it repeats the action.
- When no browser page is in focus, the Bot gets the list of open tabs.
- Opening a page or clicking now counts as looking at the screen, so the next action is not refused.
- A workspace alias problem no longer stops terminal, file and desktop actions.

## New abilities

- Web search can filter by date range (day, week, month, year) and by website.
- Google: save Gmail attachments, read and export Drive files, and create Calendar events. Creating an event is a write and is reviewed like other writes.
- Email drafts: Cc, Bcc and replies in a thread. You can edit or remove the Cc and Bcc before you send. The draft says when Gmail cannot send yet and how to fix it.

## Answers and group chats

- The final-answer check is skipped only when every tool in the run confirms its own result, and never in scheduled runs. When it stops an answer, it says which claims lack support.
- Refusals in group chats (handoff, wake, task ownership) now say what to do instead.
