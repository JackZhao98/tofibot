# TOFI v0.6.3-rc.26

Fixes from the live checks of the new Skills.

## Bots

- **Screenshots as files.** A screen capture or a browser snapshot can now be saved as a file on the Bot computer, so the Bot can edit it (for example mark it up) and send it. A browser snapshot can take the whole page. Pages that show a secret input or a private address are not saved.
- **GIFs use the size you allow.** When you ask for a GIF under a size, the Bot picks the largest picture and the smoothest frame rate that fit, instead of the first small one.
- **Checked facts stay in the answer.** Before a Bot sends its answer, it checks the answer against its work. A number or fact that the Bot can confirm from its files now stays in the answer, instead of being dropped.
