# General

Open this page: [General](/settings/general)

|---|---|---|---|---|---|
| Theme | `account.appearance` | system, light, dark |  | direct | `/settings/general#appearance` |
| Interface language | `account.language` | a language code, or empty for automatic |  | direct | `/settings/general#region` |
| Chat notifications | `account.notify_chats` | on or off |  | direct | `/settings/general#chats` |
| Task result notifications | `account.notify_tasks` | on or off |  | direct | `/settings/general#chats` |
| Primary Assistant | `account.primary_bot` | text |  | confirm | `/settings/general#primary` |
| Show activity in chats | `account.show_activity` | on or off |  | direct | `/settings/general#chats` |
| General | `account.sign_out` | not available to the tool |  | forbidden: the person changes it on the page | `/settings/general#account` |
| Timezone | `account.timezone` | an IANA timezone name |  | direct | `/settings/general#region` |
