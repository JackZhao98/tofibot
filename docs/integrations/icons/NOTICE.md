# Provider icon candidates

These are unmodified SVG files supplied by the named vendors for integration identification, with the vendor bytes and SHA-256 hashes retained in manifest.json. GitHub and Discord own their respective trademarks. TOFI catalog curation does not imply vendor endorsement. These candidates are kept outside public UI assets pending review.

GitHub: https://brand.github.com/foundations/logo and https://brand.github.com/GitHub_Logos.zip. Black and white clearspace marks are preserved. The color filename deliberately uses the same official black mark as monochrome; no alternate palette is invented. Do not alter the mark or add effects, substitute a mascot, or imply affiliation.

Discord: https://discord.com/branding. Black, white and official Blurple symbol files are supplied by that page. Retain the Discord name next to the symbol, maintain clearspace, and do not distort or reconfigure the mark.

Soft/cute is a proposed name for TOFI-owned presentation surrounding an unchanged mark, subject to each brand's applicable permissions. No stylized vendor logo is distributed. Notion, Slack and Yahoo variants are recorded as held rather than invented or inferred from an icon library's blanket license. Simple Icons warns that its CC0 package license does not determine every included brand mark's rights: https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md.

The existing TOFI library has 144 original named glyphs, outline/filled pairs, a 24×24 viewBox and currentColor. Those drawings remain unchanged; they are suitable generic fallbacks, not provider brand marks.
