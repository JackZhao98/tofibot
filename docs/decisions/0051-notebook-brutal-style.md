# 0051 风格定为“笔记本粗野”：保留新粗野主义 + 毛玻璃，按主次阶梯分配

> 编号 D51，索引见 [README](README.md)。2026-10-22 凌晨 owner 拍板。

## 决定

TOFI 的风格是新粗野主义（Neo-brutalism：粗墨线、实心错位硬投影、按下去沉进投影的按压）+ 笔记本拟物（纸、点格、猫）+ 毛玻璃。不换风格，只按 [style-notebook-brutal.md](../design/style-notebook-brutal.md) 拧紧。owner 在该文 §10 的选择：

1. **主次阶梯照稿落地**：L3 桌面/窗（3 px 墨线 + `--hard`，每屏最多一个）、L2 按键（2 px + `--hard-sm` + 2/3 px 按压，按了会发生事或改选择的东西）、L1 纸（1 px `--line-soft`，读和列的东西）、L0 玻璃（底下有东西在滚动）。
2. **置顶卡保留墨线卡，缩成一排**（60 宽横排，只有当前项是 L2）。不在第一波。
3. **深色墨线**：`--line` 用真墨色 `#0b0907`，硬影 `--hard-ink` 为 `#000`，卡片底色各提亮一档。
4. **第一波范围**：按压令牌（`--hard-ink`、`--press-lift`、`--press-travel`）+ 深色修正 + 按阶梯删掉多余的硬边 + 一行工作过程（已在 `night/quiet-process-line` 做完）。入口包体积不增加。
5. 配色想法（§9）仍待讨论，未定。

## owner 的话

“它偏离了我们的原本的风格……让它延续这个风格，看看哪里该删掉，哪里该增加……配色什么的我们都可以商量，只是说别一下这个风格给我变了就行。”关键词：notebook、拟物化、按起来很有立体感、该简约的地方简约、主次分明。最满意的是发送按钮按下去的动画。
