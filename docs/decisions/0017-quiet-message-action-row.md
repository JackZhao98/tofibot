# 0017 消息操作行放在消息下方，样式低调

> 编号 D17，索引见 [README](README.md)。

## 决定

- 每条消息的操作按钮（复制、回复、反应等）放在这条消息正下方的一行里，不放在消息上方浮动。
- 样式低调：没有外框、底色和阴影，只有一排淡色线条图标加相对时间。owner 用 “Trivial” 形容这种样式。
- 消息间距加大，给这一行预留位置，保证操作行出现时不压住任何内容。

## 日期

2026-10-20（Pacific）

## 谁拍板

owner（jackzhao）。原话由协调者整理在本次文档工作的上下文文件里，仓库内没有原始对话记录。

## 背景

之前的悬停操作栏是一个浮在消息上方的胶囊，会挡住上一条消息的最后一行（`bfab118` 提交说明）。

## 理由

- 不遮住内容和按钮：操作行出现时不能压住其他消息。
- 控件要低调：不用容器，操作行就不会和消息内容抢注意力。
- 操作行的 28 px 在悬停设备上始终预留，所以显示或隐藏它都不会让页面跳动（`bfab118`）。

## 影响

- 实施状态：已实施：`bfab118`（合并 `17bb4b7`）
- 首个仍存在的含此改动的标签：v0.1.4-rc.26（更早的 rc 标签已按 [D25](0025-github-release-cleanup.md) 清理）
- 消息间距：同一发送者连续消息之间 32 px，换发送者时 42 px（`bfab118`）。
- 悬停移入时没有淡入；鼠标离开、进入两条消息之间的空隙时，操作行多保留 120 ms 宽限。
- 触屏仍然轻点打开，触控目标 44 px。
- D16 的已送达和已读标记放在这一行末尾，紧挨时间（`1d2b322`）。
