`33a1f83e9f6b0df575f0d2071943ce2bf391a35e`. Source review of the resulting tree is
required. Source/synthetic acceptance does not prove deployment or live quality.

The default mode is OFF. Production has an empty independently qualified policy
registry. Remote descriptions, read-only annotations and model advice cannot grant
execution authority. No public-search pilot, real tool registration or scheduled
authorization lineage is added. OFF uses zero reviewer requests; selecting AUTO
with no qualified policy still cannot auto-execute any tool.

semantic authorization, setup/readiness, missing context and terminal validity.

without retries, alternate models or fallback tools. Durable exact bindings and

execution qualification remains a separate backend policy.

`portability_provenance(kind,target_id,source_json)` table. It imports no data,
routes, archive formats or UI. New native single/multi-bot ingress records authorship

old messages. Generic AddMessage, bot, legacy and scheduled content stay untrusted.

cannot confer consent. The complete original transcript stays ordinary context.

the original imported-history attack shape without calling an absent importer.
