## 1. 总评

1. **底子是好的，问题在"用力均匀"**：暖色纸面、猫、Fredoka 标题是独一份的身份，但 3 px 墨线 + 硬偏移阴影这套"贴纸"手法被用在了输入框、设置窗、置顶格、首屏卡、每个按钮、每张问题卡上——什么都强调，等于什么都没强调。
2. **信息层级倒挂**：最重的视觉（输入框的黑框）承载最少的信息；最重要的信息（Bot 在干什么、要我做什么、电脑现在什么状态）只有一只小猫和一行 12 px 的灰字。
3. **"两眼一黑"不只是设置**：首屏说"创建你的第一个 Bot"，引导三步讲的是模型和连接，从头到尾没有一句"你可以把什么交给它"；`trust.md` 已经有答案了，界面没用。
4. **一致性欠账比美感欠账大**：圆角 20 种、字号半像素、阴影 5 种模糊投影、遮罩 8 种写法、英文词混在中文界面（"Hidden Bots"、"Skills"）、连接目录的卡片把链接甩到卡外——这些比任何"风格"都先被用户看到。
5. **建议方向是"纸与猫"（Paper & Cat）**：保留暖纸和猫，把硬边收敛到每屏一件"活物"（输入框）和猫身上，其余全部改软层级；字体、圆角、阴影各收敛成一个刻度；首屏改成"能交什么"。第 1 阶段只动令牌和 CSS，0 字节进入口包，一个下午能看到最大的观感提升。

## 3. 改版提案：纸与猫（Paper & Cat）

### 3.1 一句话

**纸是安静的，猫是活的。** 界面的一切"面"（侧栏、时间线、设置、卡片）退回到纸：一层暖色、1 px 软线、一种浮起阴影；界面的一切"活物"（猫头像、输入框上的猫、空状态的猫、正在干活的指示）保留并加强。硬边墨线只留给**每屏一件**东西——聊天屏是输入框（它是桌子，猫趴在上面），引导屏是那张卡，其余全部软化。

### 3.2 视觉语言

| 维度 | 现在 | 提议 |
|---|---|---|
| 纸 | `--bg #f1efeb` 底、`--surface` 卡、`--sunk` 侧栏，三者差 4–6 个灰阶 | 保留三色，但**侧栏与主区同色**（`--bg`），用 1 px `--line-soft` 分隔；卡片只在需要"拿起来"时用 `--surface`，默认直接写在纸上 |
| 线 | 3 px `--line #2a2019` 到处用 | **`--edge-bold` 只给输入框和引导卡**；按钮、分段、卡片、设置窗、置顶格全部改 1 px `--line-soft`；主按钮用实色填充不描边 |
| 影 | `--hard` 77 处 + 5 种模糊投影 | `--hard` 只跟 `--edge-bold` 同行出现；其余一律 `--shadow-float: 0 10px 28px rgb(0 0 0/.12)`（深色 `.4`）；菜单/弹层 `--shadow-pop: 0 4px 14px rgb(0 0 0/.10)` |
| 猫 | 头像、输入框上的猫、空状态、引导 | 不变，加两条规则：① 猫的动画时长走 `--m-loop`/`--m-loop-slow`；② 猫表达的状态（睡/工作/等你）**必须同时有一行文字**在顶栏状态行里，猫是插画不是唯一信号 |
| 电视框 | 深色外壳 + 深色玻璃下巴 | 外壳保留，下巴改成纸色（`--surface` + 1 px 线），"你 / Bot"切换用分段控件；小窗在 < 1024 px 改为**停靠在输入框上方的横条**（不盖消息） |
| 强调色 | clay 五处用 | clay 只给：主按钮、发送按钮、进度/选中指示。悬停提示改中性（C22 关闭）；禁用态灰色；焦点环蓝色不变 |
| 密度 | 侧栏行 66 px、消息间距 28–36 px、设置行 72 px | 侧栏行 56 px、消息同发送者 20 px / 换人 28 px、设置行 56 px；正文 15 px 不变，时间线最大宽 760 → 720 |
| 字 | Fredoka 标题 + PingFang 正文 + JetBrains Mono 次要信息 | Fredoka **只给**：Bot 名字、hero、数字徽章；UI 标签改 `--body` 500；等宽**只给**：代码、ID、主机名、键盘快捷键。时间戳、分组标题、日期分隔改 `--type-meta` |

### 3.3 令牌改动（第一阶段全部可只改 `design-tokens.css` + 调用点）

**颜色**（浅色 → 深色）

```css
/* 表面：侧栏与主区同色；深色改为"越近越亮" */
--bg:#f1efeb;        /* dark #15130f */
--surface:#fcfbf9;   /* dark #1e1b17 */
--surface-2:#f5f3ef; /* dark #27231e */
--sunk:#e9e6e1;      /* dark #110f0c  —— 只给输入区底和代码块 */
/* 线：深色墨线不再是奶白 */
--line:#2a2019;      /* dark #0b0907  —— 硬边只在输入框/引导卡 */
--line-soft:#dcd8d1; /* dark #352f28 */
--line-hover:#c9c3ba;/* dark #4a423a  —— 新，替代 --surface-hover 这种骗人的别名 */
/* 四色改名，别名一个版本后删 */
--clay / --iris / --lagoon / --honey  （删 --yellow/--pink/--blue/--orange）
/* 新：用户气泡有归属感 */
--bubble-user:color-mix(in srgb,var(--clay) 9%,var(--surface));   /* dark 14% */
/* 新：一个遮罩、一个浮影 */
--scrim:rgb(20 18 15/.42);           /* dark rgb(0 0 0/.6) —— 替代 8 种写法 */
--shadow-float:0 10px 28px rgb(0 0 0/.12);  /* dark .4 */
--shadow-pop:0 4px 14px rgb(0 0 0/.10);     /* dark .35 */
--hard:3px 4px 0 var(--line);               /* 引用，不写死（C10）；深色同 */
--hard-hover:4px 5px 0 var(--line);         /* 新（C9） */
/* 悬停提示改中性 */
--hint-bg:var(--inverse); --hint-ink:var(--on-inverse);
```

**字体刻度**（8 档 + hero，行高 5 档，`tokens.md` T7 落地）

```css
--type-hero:700 36px/1.08 var(--display);     /* 只给引导与首屏 */
--type-title:700 20px/1.25 var(--display);    /* 页标题 */
--type-name:600 15px/1.3 var(--display);      /* Bot 名字（新）*/
--type-body:400 15px/1.6 var(--body);
--type-ui:500 14px/1.4 var(--body);           /* 按钮、行标题、菜单项（新，替代 --type-button 的 Fredoka）*/
--type-meta:400 13px/1.5 var(--body);         /* 时间、预览、说明 */
--type-label:500 12px/1.3 var(--body);        /* 分组标题，不再等宽不再大写 */
--type-code:400 13px/1.6 var(--mono);
--type-chip:600 11px/1 var(--mono);           /* 状态标签，唯一的等宽小字 */
```

删：`--type-button`（Fredoka 按钮）、`--type-status`、`--label-tracking`；半像素字号归档到最近的整数；字重 550/650 归 500/600。

**圆角**（6 档，`tokens.md` §4 的提议原样采纳）

`--radius-xs 6` 徽章 · `--radius-sm 10` 行内按钮/菜单项 · `--radius-md 12` 按钮/输入 · `--radius-lg 16` 卡片/菜单/气泡 · `--radius-xl 22` 大面板/设置窗/输入框 · `--radius-pill 999`。删 `--r`、`--r-lg`、`--radius-2xl`。

**层级（elevation）**：四级，和 z-index 刻度（§9.3）是两回事：

| 级 | 用途 | 边 | 影 |
|---|---|---|---|
| 0 纸 | 侧栏、时间线、设置页体 | 无 | 无 |
| 1 卡 | 问题卡、审批卡、设置分组、会话行悬停 | 1 px `--line-soft` | 无 |
| 2 浮 | 菜单、弹层、toast、电脑小窗 | 1 px `--line-soft` | `--shadow-pop` |
| 3 窗 | 对话框、设置窗、电脑放大 | 1 px `--line-soft` | `--shadow-float` + `--scrim` |
| ★ 活物 | 输入框、引导卡 | 3 px `--line` | `--hard` |

**间距**：4 pt 网格，`--space-1..6 = 4/8/12/16/24/32`；组件内 8/12，组件间 16，区块间 24/32。

## 4. 备选方向

| 方向 | 一句话 | 代价 / 风险 | 保留身份？ |
|---|---|---|---|
| **A. 纸与猫（推荐）** | 面退回纸、硬边只给活物、三套刻度收敛、首屏讲"能交什么" | 第 1 阶段只改令牌与 CSS；视觉差异明显但不陌生；需要 owner 接受"硬边变少" | 全部保留 |
| B. 贴纸本（更玩） | 反其道：硬边、点纸、贴纸标签全面铺开，猫更多动作，颜色更饱和 | 和"专业工具"的自托管用户气质相反；深色模式更难做；每屏更重 | 加强 |
| C. Linear 式密集 | 去圆角到 6–8、行高 44、灰阶为主、单色图标、猫只剩头像 | 身份被稀释到只剩头像；owner 已定保留猫和电视框 | 弱化 |
| D. 极简留白（ChatGPT 式） | 无侧栏分色、无卡、正文居中 680、所有 chrome 退到悬停 | 群聊、电脑窗、审批卡这些"多东西"的屏会失去结构 | 弱化 |
| E. 电视机房 | 把电视框当主题：每个 Bot 一台电视、聊天在屏幕里、下巴是控制台 | 新鲜，但是一次"自创交互"，违反 D28；性能上多层框 | 变形 |

**推荐 A**。理由：它是唯一同时满足"大胆改观感""不删身份""第 1 阶段 0 字节入口包"的方向；B 和 E 会让深色与手机更难；C 和 D 是在删 owner 定过要留的东西。
