## 0. 一句话

**TOFI 的风格一直是三样东西叠在一起：新粗野的墨线和硬影、笔记本的纸和猫、浮在滚动内容上的毛玻璃。** 它的问题从来不是"太粗野"，而是粗野待遇**发得太均匀**（上一轮总评第 1 条仍然成立）。修法不是把墨线拿掉，而是写一把梯子：谁拿 3 px，谁拿 2 px，谁是纸，谁是玻璃——让按下去会发生事的东西最重，读的东西最轻。

## 2. 先研究真东西：发送键为什么好按

今天的按压（`v2-foundations.css:12-36`，发送键 `v2-app.css:313-321`）：

| 态 | 位移 | 阴影 | 时长 / 曲线 |
|---|---|---|---|
| 静止 | 无 | `--hard-sm` = `2px 3px 0` 墨 | — |
| 悬停 | `translate(-1px,-1px)` | `3px 4px 0 var(--line)`（**写死**，深色下变奶白，C9） | `--m-press` 120 ms `--ease-out` |
| 按下 | `translate(2px,3px)` | `none` | 同上 |
| 松开 | 回到静止 / 悬停 | 回到对应值 | 同上 |
| 减少动效 | 无位移 | 仍塌掉 | `transition:none` |

它好在三件事，缺一不可：

1. **行程 = 影子的偏移。** 静止时影子在右下 (2,3)，按下走 (2,3)，影归零——按钮**正好落在自己的影子上**。眼睛读到的是"一块实物压到了桌面"，不是"按钮变暗了"。这是整套风格的物理学，所有 L2 控件都得遵守：行程和 `--hard-sm` 的偏移是同一对数。
2. **悬停先抬 1 px、影子长 1 px。** 光源一致：抬起来影子就长。按下前有一个"预备"，按下的落差从 (−1,−1) 到 (2,3) 共 3/4 px，比表面上的 2/3 px 更大，所以感觉"强"。
3. **120 ms、`--ease-out`、不回弹。** 低于反应阈值，快速减速落地；没有 `--ease-spring`。按键是重物，不是小球。

缺口：悬停影色写死、深色下阴影和描边都失真（§6）；JS 侧 Space/Enter 的按压没有和 `:active` 对齐（Enter 在多数浏览器不触发 `:active`）；置顶格、分段选中项、问题卡选项各自写了一份行程，有的 (1,1)、有的 (2,2)（`owner-setup.css:7`、`question-card.css:36-38`）。

**毛玻璃清单（今天）**：`backdrop-filter` 出现在 21 个文件 36 处。按角色分三类——① 浮在滚动内容上的：输入框底（`--glass`，Web 下由渐变模糊条代为模糊，`progressive-blur.css:26-30`）、顶栏两枚胶囊背后的渐变模糊、图片动作条、电脑窗悬浮控件、只读会话的头尾；② 弹出来的：菜单（`--glass-strong` + 32–40 px）、附件菜单；③ 遮罩：设置窗背后 10 px、删除对话框 6 px、交接 / OAuth 12 px、文件拖放 12 px、终端确认 4 px、启动画面 12 px。①②保留并写进梯子 L0；③的模糊半径有 6 种，收敛成两档（§4）。

## 3. 层级梯（hierarchy ladder）

判据一句话：**按了会发生事的东西才有资格拿墨线和硬影；读的东西是纸；底下在滚的才是玻璃；每屏只有一张桌子。**

| 级 | 待遇 | 谁 | 判据 |
|---|---|---|---|
| **L3 桌面 / 窗** | 3 px `--line` + `--hard`（3/4 px）+ 圆角 `--radius-xl` 22；**不按压**（它是容器） | 输入框、模态对话框、设置窗、引导卡 / 首屏卡、电脑放大态 | 每屏在视线里**最多一个**。它是"本子"或"桌子"，别的东西放在它上面 |
| **L2 按键** | 2 px `--line` + `--hard-sm`（2/3 px）+ 按压（§5）+ Fredoka 600 | 主 / 次按钮、发送键、审批卡与问题卡的选项和按钮、分段控件的**选中项**、开关、首屏任务卡、置顶格的**当前项**、设置左栏的书签指示器、配对数字、危险按钮 | 按了会**发生事**或**改选择**。一组同类里只有"当前那个"拿墨线（分段、置顶、书签） |
| **L1 纸** | 1 px `--line-soft`，无影；悬停只变底色（`--surface-2`）；按下变 `--sunk` | 卡片（归档、记忆、日程、连接、验证）、会话行、用户气泡、系统行、交接胶囊、图标按钮、下拉、搜索框、输入框里的 "+" 和麦克风、工具步骤、工作行、设置页内分组、toast | 读的、列的、放东西的 |
| **L0 玻璃** | `--glass` + `--blur` + 1 px `--glass-edge` + `--sheen`；可以套在 L3 的墨框里 | 输入框的底、顶栏身份胶囊与动作胶囊（在渐变模糊上）、菜单与弹出卡（`--glass-strong`）、图片动作条、电脑窗悬浮控件、模态遮罩 | 底下有东西在**滚**或**动**；玻璃从不单独承重——要么有 1 px `--glass-edge`，要么装在 L3 的墨框里 |

新组件怎么放：先问"按了会发生什么"。会改变世界（发送、确认、批准、保存、交出去）→ L2；只是切换视图或选项 → L2 但只给当前项；什么都不发生 → L1；它浮在会滚的内容上 → L0 的底 + 上面那一级的边。再问"这一屏的桌子是谁"：已经有一个 L3 在视线里，新东西不能再是 L3（对话框打开时它取代输入框成为桌子；设置窗打开时聊天被遮罩）。

## 4. 笔记本拟物：怎么保持极简

**原则**：纸的线索只放在**空白等你写的地方**和**页面的边缘**，永远不放在正在读的正文后面。拟物是"这本子是真的"，不是"每页都画格子"。

| 线索 | 用在哪 | 禁止在哪 | 今天 |
|---|---|---|---|
| **点格纸** `--dots` | 空白页：引导卡、空状态卡、问题卡、头像舞台、团队板 | 时间线、设置页体、任何有一段以上正文的地方 | 已有 7 处，全部合规；保留 |
| **页边线**（笔记本左侧那条线） | 工作行展开后的步骤清单左侧（`--edge` solid `--rule`）、工具步骤抽屉、引用块 | 正文段落左侧 | `web-tool-steps.css` 已经是这条线（`border-left:var(--edge) solid var(--line-soft)`）；只是给它名字 `--rule` |
| **虚线页眉** | 引导卡：猫站在页眉上（`first-run-cats` 的 `dashed`） | 任何卡内分隔（用 1 px `--line-soft`） | 已有；保留，只此一处 |
| **书签 / 页签** | 设置左栏的当前页（L2 卡片滑动）；分段控件的选中项 | 顶栏、侧栏会话列表 | `settings-rail-indicator` 就是它 |
| **便签 / 信纸** `--sticky`、`--paper-*` | 邮件草稿、寄信动画、显示卡 | 聊天气泡、设置 | 已有；保留 |
| **装订 / 线圈边** | 不做 | 到处 | — |
| **纸纹** | 不做（每帧成本，点格已经给了质感） | 到处 | — |
| **页角卷边** | 不做 | 到处 | — |
| **猫** | 头像、输入框上、空状态、引导、右下角 | 顶栏第二只（D23） | 保留；**思考行旁边的小猫替换成小转圈**（§7，owner 今晚的要求） |

## 5. 按压物理：写成令牌

今天的数都对，问题是它们散在 CSS 里、互相不引用。加三个令牌，改两处写死：

```css
/* 新 */
--hard-ink:#2a2019;                 /* 硬影的墨色；深色 #000。和 --line 解耦：描边可以换色，影子永远是墨 */
--press-lift:-1px -1px;             /* 悬停抬起 */
--press-travel:2px 3px;             /* 按下行程 = --hard-sm 的偏移，两者不许分家 */
/* 改 */
--hard:3px 4px 0 var(--hard-ink);   /* 原来写死 #2a2019（C10） */
--hard-sm:2px 3px 0 var(--hard-ink);
--hard-hover:3px 4px 0 var(--hard-ink);  /* 替掉 3 处写死的 3px 4px 0 var(--line)（C9） */
```

为什么只加这三个：`--hard-ink` 已被 `mail-send-flight.css:2,6` 引用却从未定义（C7，寄信动画的硬影因此不显示）；`--press-*` 是为了让"行程 = 影子偏移"成为一条可被 `test:motion-tokens` 守住的等式，而不是五个文件各写一遍。时长和曲线**不加新令牌**：按压就是 `--m-press` 120 ms + `--ease-out`，按下和松开同一档。

| 态 | 规则 |
|---|---|
| 静止 | `box-shadow:var(--hard-sm)`；`transform:none` |
| 悬停 | `transform:translate(var(--press-lift))`；`box-shadow:var(--hard-hover)`；填充 88% 混 `--surface` |
| 按下（`:active` 和 `.is-pressed`） | `transform:translate(var(--press-travel))`；`box-shadow:none` |
| 松开 | 回静止或悬停，同 120 ms `--ease-out`；**不用** `--ease-spring`（它是"小物体到达"的曲线，不是按键的） |
| 禁用 | `opacity:.45`，无影，无位移；发送键例外：虚线 1.5 px `--line-soft` 无底（今天就是这样） |
| 键盘 | Space / Enter `keydown` 加 `.is-pressed`，`keyup` 去掉并触发；和 `:active` 同一组样式（Enter 不触发 `:active`，P8） |
| L3 容器 | 不按压。被当按钮用的 L3 不存在；要能按就是 L2 |
| 开关 | 轨道 L2 墨边；拇指自带 `1px 1px 0 var(--hard-ink)`，按下走 (1,1) 影归零；切换 120 ms |
| 分段 / 置顶 / 书签 | 只有当前项是 L2，按下同样走 (2,3)；非当前项按下只变底色 |
| 减少动效 | `transition:none`；悬停和按下都 `transform:none`；只保留影子塌掉和底色变化（当帧，P3）。开关拇指瞬移 |
| 触屏 | 同鼠标；点击区 ≥ 44 px 由外层留（P8） |

守卫：`test:motion-tokens` 加一条——`translate(` 里出现的像素对只能是 `var(--press-*)`，`box-shadow` 里的 `0 #` / `0 var(--line)` 硬影只能是 `var(--hard*)`。

## 6. 深色模式

今天深色把 `--line` 改成奶白 `#f1e6d6`、硬影改成纯黑：3 px 奶白框 + 黑影，比浅色更吵（上一轮 L1，高）。墨线的意思是"墨"，在深纸上也该是墨。

| 令牌 | 浅色 | 深色（今天） | 深色（提议） |
|---|---|---|---|
| `--line` | `#2a2019` | `#f1e6d6` | **`#0b0907`** |
| `--hard-ink` | `#2a2019` | （`#000` 写死在 `--hard`） | `#000` |
| `--surface` / `--surface-2` | — | `#1f1c18` / `#2a2621` | `#231f1a` / `#2e2924`（各抬一格，让墨边在深纸上读得出来；**待讨论**，§9 选项 A） |
| `--glass-edge` | `rgba(42,32,25,.14)` | `rgba(241,230,214,.2)` | 不变——玻璃边在深色下本来就该是浅的，它是高光不是墨 |
| `--glass` | `.58` | `.52` | 不变 |

深色下的硬影：黑影落在深纸上对比小，所以 L2 的"抬起来"靠**面色比底色亮一格**来读（`--surface` 对 `--bg`），而不是靠影。这就是为什么要抬面色。实验台里切"当前 / 深色"可以直接对比。

## 7. 工作行（owner 今晚的要求）

Bot 在干活时，时间线末尾一行**细灰字**：

```
◌ 正在读日历 · 12 s ›
```

- 字：`--type-meta` 12 px `--muted`；秒数等宽 `--mono` 11 px，`tabular-nums`，每秒走一下。
- 指示器：12 px 圆环，1.5 px 线，四分之三是 `--muted` 28% 透明，四分之一是 `--muted`，1 s 匀速转。减少动效：不转，画成两段实线。**它替掉思考行旁边的小猫**。
- 点击（或 Enter / Space）展开步骤清单：左侧一条页边线（§4），每步一行 `--type-meta` `--ink-soft`，完成的绿点、进行中的小转圈、右侧用时。展开 280 ms `--m-panel-in` `--ease-out`，用 `grid-template-rows:0fr→1fr`。
- 层级：L1 以下——没有边、没有底、没有影，悬停只把字从 `--muted` 提到 `--ink-soft`。它是全屏最安静的一行；输入框上的猫仍是"谁在干活"的唯一插画（P1 第 3 条），顶栏状态行是它的文字版。
- 文案走 `thinkingHeadline()` 的标题或工具名，没有就是"正在思考"；不写"让我看看""稍等"。
