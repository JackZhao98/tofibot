## 1. 第一印象：一个新用户第一次打开设置

我假装自己刚装好 TOFI，建了一个 Bot，点开右上角"设置"。左边是四组 11 个页面：**你**（通用）、**Bot 可用**（连接、Skills、审批、跟进事项（预览）、模型、自动行为）、**工作空间**（电脑、密钥与机密、用量）、**系统**（高级）。逐页走一遍，记下每一处卡壳。

### 1.1 左栏本身

- "**你**"和"**Bot 可用**"不是任何产品里见过的分组名。"Bot 可用"下面放着"模型"和"审批"，可这两样不是"Bot 可用的东西"，是我给 Bot 定的规矩。分组是按系统结构分的（人 / Bot / 机器 / 系统），不是按我要干什么分的。
- "**工作空间**"里是"电脑、密钥与机密、用量"。用量和电脑有什么关系？密钥与机密跟"模型"页里的 API key 又是什么关系？（答案：不是一回事，一个是给 Bot 的电脑用的环境变量，一个是模型供应商的 key。新用户不可能知道。）
- "**跟进事项（预览）**"带括号，一看就是没做完的东西混在正式菜单里。
- "**Skills**"是唯一的英文菜单项，其它都是中文。

### 1.2 通用

账户、外观、主助理、语言与地区、对话、通知。基本正常，两处卡壳：

- "**主助理**：负责你日常杂事的 Bot。始终有且只有一个。"——我刚建了一个 Bot，为什么要在设置里再选一次"主助理"？这个概念在聊天界面里从没出现过。
- 一条蓝色横幅："**在找导出、服务器信息或从头开始？它们已移到'高级'。**"——我是新用户，我没有在找。这是给老用户的搬家通知，却永久挂在新用户面前。
- "**在对话里显示工作过程**"：能懂，但它和"自动行为"里的"结构化回复"是一回事的两面（一个管发什么，一个管显示什么），分在两页。

### 1.3 连接

"连接你的工具"，一个目录加"添加"。能懂，这是 Claude 的 Connectors。
自定义表单里有"连接方式 / metadata URL / client id / client secret / scopes / allowlist / denylist / headers"——这是给开发者的，默认全部摊开。

### 1.4 Skills（owner 说"乱七八糟"的那页）

页面从上到下：

1. 一行小字"**工作区 Skill · 按需读取 · 可限定给指定 Bot**"加"安装 Skill"按钮。三个词我一个都不理解：什么是工作区 Skill，什么叫按需读取，为什么要限定给 Bot。
2. 一块"**Tofi 工作技能**"，三个可点的卡片：资料调研、网页验收、文档交付。点一下就"已安装"。这是什么？是推荐模板。
3. 然后是列表。最上面五张卡片，名字是英文代码 **`spreadsheet` / `document-report` / `slides` / `web-page` / `code-delivery`**，各带一个"内置"标签、一个"启用此技能"开关、一行"谁能用：所有 Bot · 更改"。
4. 再往下才是我自己装的 Skill，每张也有"谁能用"，多一个"移除"。

**这五个"内置"到底是什么？** 读了代码才知道（D41）：它们是产品自带的"交付能力"——让 Bot 做表格、写报告、做幻灯片、做网页、交付代码时，先读一份"怎样才算做好"的说明并把检查脚本复制到电脑上。它们**不是用户概念里的 Skill**，是产品能力。把它们和用户装的 Skill 混在同一个列表、用英文代码当标题、再给每个配两套开关（启用 + 谁能用），新用户没有任何办法理解。

**"谁能用"**：点"更改"弹出"所有 Bot / 仅限所选 Bot"加勾选列表。我有一个 Bot，这个选项对我毫无意义；有五个 Bot 的人，也很难想出为什么要不让某个 Bot 读一份文档。Claude 的 Skills 就是一个开关、全账户生效。

小结：这一页上一个 Skill 有 **3 层概念（推荐模板 / 内置 / 已安装）× 2 个开关（启用 / 谁能用）**，而它应该是"一个列表、一个开关"。

### 1.5 审批

一个下拉"**当前账号的审批模式**"：关闭 · 保留原有审批规则 / 观察 · 记录建议，保留原有执行路径 / 自动 · 审查后按执行策略决定。下面一段说明："审查范围：所有外部工具。审查建议与执行权限分别判断。"再下面一条横幅"更多控制即将推出"。

- "审查员"是谁？"原有审批规则"是什么？"执行权限"和"审查建议"为什么分开判断？全是内部术语。
- 这个下拉和"自动行为 › 检查与审批 › 工具调用自动复核"是**同一个存储、同一个值**（`putAutoReviewMode`），两页各放一份，文案还不一样。
- 真正跟"审批"有关的东西——"常驻许可"（我点过"始终允许"的工具）和"在对话中记住的批准"——反而不在这一页，在"自动行为"的最底下。

### 1.6 跟进事项（预览）

一个黄色横幅"仅预览，不会发送任何内容"，然后每个 Bot 一个下拉"关闭 / 预览"，一组统计（扫描次数、新增事项、已跳过、模型费用、你的评价），再是"将会提醒你 / 每周汇总 / 已处理"列表，每条带"有用 / 烦人 / 已处理过"三个按钮，最后"限制：每日提醒数、每日扫描预算、安静时段"。

这是一个**功能实验的仪表盘**，不是设置。新用户看到的是一堆零和"等待首次扫描"。Claude 的做法是把没定型的功能放在"功能预览（Feature preview）"一个开关后面，不单独给页。

### 1.7 模型

左栏"**模型提供方**"：Codex（设备登录）、OpenAI（API key）、Anthropic（API key + **Workspace ID**，注释教我去 Claude Console 的 Settings → Workspaces 找 `wrkspc_` 开头的串）。
下面"**新 Bot 的默认设置**"：模型下拉 + "思考强度"分段控件。
右栏"**语音听写**"："转写模型 gpt-4o-mini-transcribe（$0.003/分钟）/ gpt-4o-transcribe（$0.006/分钟）"。

- "新 Bot 的默认设置"这个标题就错了：它是**所有跟随全局的 Bot** 的模型，不只是新 Bot。而且同一个值在"自动行为 › 模型 › 对话模型"又出现一次（同一个写路径 `applyConversationModel`）。
- 语音听写放在"模型"页右栏，还要我选 OpenAI 的转写型号并看单价。Claude 和 ChatGPT 的语音输入就是一个麦克风按钮，没有型号选择。
- "Workspace ID"是 Anthropic Console 的概念，99% 的用户不需要。

### 1.8 自动行为

7 组 14 项，加"常驻许可"和"在对话中记住的批准"两块。owner 说这页"挺好"，我同意结构是对的（每项：名字、一句人话、默认值、改过的标记、重置）。卡壳的是其中几项的**内容**：

| 项 | 第一次读到的反应 |
|---|---|
| 对话模型 | 和"模型"页重复 |
| 后台模型："选'自动'时，用 Claude 就走 Haiku" | 在设置里出现厂商和型号名 |
| **Haiku 必须使用回复工具** | 完全不懂。什么是回复工具？为什么只有 Haiku？ |
| 联网搜索："Claude 模型会先自行上网搜索" | 为什么只说 Claude |
| 保留原文的自己的回复：1–20 | 不懂这个数字在调什么 |
| 定时和后台任务交付前先复核：0–5 次 | 能懂但偏技术 |
| 桌面空闲休眠："由电脑服务设定" | 只读，不能改，为什么列在"可调"清单里 |

### 1.9 电脑 / 密钥与机密 / 用量

- "电脑"：资源（CPU/内存/磁盘、重启）、运行环境、Mac 权限、其他设备。能懂。
- "密钥与机密"：按 Bot 的环境变量和 SSH 密钥。标题像是在说密码，其实是给开发者用的。它和"模型"页的 API key、"连接"页的 OAuth 是三个不同地方的三种"密钥"。
- "用量"：各 Bot 的模型消耗、各对话的上下文。能懂，但它是**账单/用量**，放在"工作空间"下面不直观。

### 1.10 高级

版本、服务器连接信息、数据迁移（导出/导入）、调试、危险区（输入 PURGE 清空）。这一页是对的，就是"高级"该有的样子。

### 1.11 汇总：为什么两眼一黑

1. **同一个值出现在两处**：对话模型（模型页 + 自动行为）、工具调用审查（审批页 + 自动行为）。
2. **厂商和型号名进了设置文案**：Haiku、Claude、Workspace ID、gpt-4o-mini-transcribe。
3. **三层 Skill 概念、两套开关**，内置能力用英文代码当标题。
4. **实验仪表盘当正式页面**（跟进事项、审批页的"即将推出"）。
5. **分组按系统结构，不按人的目的**："你 / Bot 可用 / 工作空间 / 系统"。
6. **给老用户的搬家横幅永久挂着**。
7. 全部 11 页约 **90 个可操作控件**（不含表单字段），而 Claude 的设置总共约 30 个。

## 3. 新拓扑（mock）

原则：按"我想干什么"分组；一个值只有一个家；左栏用 Claude / ChatGPT / Slack 都在用的词；厂商和型号名不出现在设置文案里，只出现在模型下拉的选项里；没定型的功能收进"功能预览"。

```
设置
├─ 通用            账户、外观、语言、时区、通知
├─ 模型            连接供应商、默认模型、思考强度
├─ 连接器          外部服务（MCP）
├─ 技能            产品能力 + 我安装的技能，一个开关一行
├─ 自动行为        Bot 替我自动做的事（owner 认可的那页，去掉型号项）
├─ 权限            审批方式、始终允许、记住的批准
├─ 电脑            共享电脑、资源、设备、开发者密钥
├─ 用量            费用与上下文
├─ 功能预览        跟进提醒（实验）
└─ 高级            版本、服务器、导出导入、调试、重置
    （admin）成员   账号管理
```

11 页 → 10 页（含 admin），但控件从约 90 个降到约 55 个；更重要的是每一页的标题能回答"我来这页干什么"。

### 3.1 通用

| 控件 | 类型 | 默认 |
|---|---|---|
| 账户：登录名、修改密码、退出登录 | 行 + 按钮 | — |
| 外观 | 分段：跟随系统 / 浅色 / 深色 | 跟随系统 |
| 语言 | 选择 | 自动 |
| 时区 | 选择 | 浏览器时区 |
| 通知 | 按钮/状态 | 未开启 |
| 显示 Bot 的工作过程 | 开关 | 关 |
| 语音输入 | 开关（需 HTTPS 与已连接供应商时可用） | 开 |

去掉：主助理（移到 Bot 列表，见 §5）、搬家横幅、旧归档入口。

### 3.2 模型

| 控件 | 类型 | 默认 |
|---|---|---|
| 供应商：Claude（API key）、ChatGPT（登录）、OpenAI（API key） | 三张卡，各"连接 / 断开" | 未连接 |
| 默认模型 | 选择（按供应商分组，只列已连接的） | 第一个连接的供应商的推荐型号 |
| 思考强度 | 分段：低 / 中 / 高（随所选模型） | 模型默认 |
| 说明一行："每个 Bot 可以在自己的设置里改用别的模型。" | 文字 | — |

Anthropic 的 Workspace ID 进"高级连接选项"折叠，默认收起。
"后台任务模型"不在这页（见 3.5）。

### 3.3 连接器

与现在一致：目录 + 已连接列表。改动只有两点：自定义表单里 OAuth/headers/allow/deny 收进"高级选项"折叠；页名"连接"→"连接器"。

### 3.4 技能

```
技能
├─ 产品能力（随 TOFI 自带）
│  └─ 文件交付：表格、报告、幻灯片、网页、代码        [开关，默认开]
│      一行说明："Bot 交付文件前先按清单检查并预览。"
├─ 我安装的技能                                        [安装技能]
│  ├─ 资料调研                                          [开关]  [移除]
│  ├─ 网页验收                                          [开关]  [移除]
│  └─ …
└─ 推荐技能（未安装时显示）：三张卡片，点"添加"进上面列表
```

- 五个内置合成**一个**开关"文件交付"。五个各自开关在代码里保留为内部默认（全开），不再上 UI。
- 每个技能一个开关，全账户所有 Bot 生效。**删除"谁能用"。**
- 不再显示"工作区 Skill · 按需读取 · 可限定给指定 Bot"。

### 3.5 自动行为

owner 认可的页面，保留结构（分组、一句人话、默认值、已改标记、重置）。内容调整：

```
自动行为
├─ 回复
│  ├─ 只把正式回复发到对话里（原"结构化回复"）           开关  开
│  └─ 联网搜索                                           开关  开
├─ 记忆与历史
│  ├─ 群里已结束的讨论折成摘要                           开关  开
│  └─ 逐字保留自己最近几条回复                           选择 1–20  3
├─ 复核
│  ├─ 用过工具后再对照结果检查一次                       开关  开
│  ├─ 定时任务交付前复核（最多退回次数，0 = 关）         选择 0–5  2
│  └─ 定时任务结束前补完成记录                           开关  开
├─ 可靠性
│  └─ 模型出错时自动重试次数                             选择 0–10  8
└─ 后台任务
   └─ 后台任务（摘要、分类、复核）用的模型               选择：自动 / 具体型号  自动
```
