TOFI 风格审计 · 笔记本粗野

配合 style-notebook-brutal.md（提案，待 owner 决定）。这一轮不是新风格：墨线、硬影、按压、毛玻璃、猫、Fredoka 都是今天的 TOFI，只是把"谁拿到粗野待遇"写成一把梯子，然后按梯子该砍的砍、该补的补。每页顶部可切"提议 / 当前 / 并排"和"浅色 / 深色"。"当前"是组件目录页的真实渲染（合成数据）。字体只请求 Google Fonts，其余内联。上一轮的 纸与猫 稿原样保留，供对照。

  1. 按压实验台

    先看这个。主按钮、次按钮、图标按钮、开关、任务卡、置顶格、发送键：静止 / 悬停 / 按下 / 禁用 / 焦点，鼠标和键盘都真的会动；切"当前"看深色奶白问题。

    press-lab
  2. 聊天 · 桌面 1280

    输入框仍是唯一 L3；置顶格留而缩；顶栏加状态行；工作行（细灰字 + 小转圈 + 秒数，可展开）替掉思考行的小猫。

    chat-desktop
  3. 聊天 · 手机 390

    输入框降一档（2 px + hard-sm），硬影回来；工作行收起态。

    chat-phone
  4. 设置首页

    窗体 L3 留；左栏是纸，当前页是 L2 书签；页内 1 px 纸卡；三种控件统一。IA 按 settings-ia.md。

    settings-home
  5. 首次运行

    点格纸引导卡留；内容换成三张"放心交"的 L2 任务卡，按下去就交。

    first-run
级待遇谁判据
L3 桌面 / 窗3 px 墨线 + `--hard`（3/4 px）+ 圆角 22；不按压（它是容器）输入框、对话框、设置窗、引导卡、电脑放大态每屏在视线里最多一个；它是"本子"或"桌子"
L2 按键2 px 墨线 + `--hard-sm`（2/3 px）+ 按压 2/3 px + Fredoka主/次按钮、发送、审批/问题卡的选项与按钮、分段选中项、开关、任务卡、置顶当前项、设置书签按了会发生事或改选择
L1 纸1 px `--line-soft`，无影；悬停只变底色卡片、行、气泡、胶囊、菜单项、图标按钮、下拉、步骤列表、工作行读的、列的、放东西的
L0 玻璃`--glass` + `--blur` + 1 px `--glass-edge` + `--sheen`输入框的底、顶栏两枚胶囊、菜单、图片动作条、电脑悬浮控件、模态遮罩底下有东西在滚或动；玻璃从不单独承重
