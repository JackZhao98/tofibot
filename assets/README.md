# README header artwork

The four cats (curl, tall, loaf and bean) come from the project’s original
approved landing design. The header reuses their exact SVG snapshots, shapes,
patterns and palettes, with the landing’s warm black dots, cream borders and
apricot sticker. It does not use photographic reference material.

Fredoka 700 is the landing display font, licensed under SIL OFL 1.1; retain
OFL-Fredoka.txt. The editable banner.svg embeds the font and all vector shapes.
banner.png is the browser-rendered README image, so GitHub needs no external
font, SVG styling, scripts or assets. Project license selection remains pending.
