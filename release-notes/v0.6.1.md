# TOFI v0.6.1

Changes since v0.6.0.

## Browser

- The Browser engine now defaults to Playwright. A Bot reads the page as a list of elements with references and acts on them directly: click, type, fill a form, select, upload a file, handle a dialog. It uses the computer's Chrome, so sign-ins stay, and every action goes through the same review as before.
- In a live test the Playwright engine finished the same tasks in about 4 steps and 30 seconds, where the Classic engine needed about 19 steps and 107 seconds.
- A workspace that never set the item uses the new default. A workspace that chose Classic keeps it. If the Playwright engine cannot start, or Chrome cannot be reached, the Bot uses the Classic browser and says so once.

## Desktop

- New optional Desktop engine, Accessibility (default stays Classic): the Bot reads desktop apps as a tree of controls, including the state of check boxes and toggles, and keeps the screenshot and coordinate tools as a fallback. Large trees are shortened.
- The computer's desktop runs one shared session bus.

## Personal computers (off by default)

- A server can let users connect their own Mac through the desktop app (`TOFI_PERSONAL_COMPUTERS=1`). The Mac decides which Bots and folders are allowed; the admin cannot see these computers. A call that times out reports that it may have run.
