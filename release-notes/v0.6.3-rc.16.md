# TOFI v0.6.3-rc.16

Fixes from the live check of rc.13. From the Mac app, the Bot opens pages in the built-in browser on the first try. From the web, a sleeping Bot computer stays first.

## Fixes

- **Mac app: the first page in the built-in browser.** The first page the Bot opened in the Mac's built-in browser failed, and the Bot went on to the next browser. The open request now uses the action of the browser that serves it.
- **A sleeping Bot computer keeps its place.** When the Bot computer was asleep, messages from the web went to the Mac first. Now the Bot computer stays first and wakes up when the Bot uses it.
- **Settings › Environments.** The features of the Mac and of the Bot computer show in groups: Connected, Disconnected and Off. The features of this Mac show on the browser source row.
- **Mac app: the Bot browser toolbar** uses the language and the theme of the chat, not those of the system (Mac app 0.2.6).
- **Work timeline:** the "N steps" groups open and close with the same motion as the other folding sections.
