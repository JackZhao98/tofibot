# TOFI v0.6.3-rc.18

Off-site backups and object storage for self-hosted servers, and side panels as widget cards. rc.17 was not released.

## Backups

- **Off-site snapshot before updates.** `tofi update` saves a snapshot to the remote backup store before it changes the server. On the Backups card you select Best effort, Required or Off. "Required" stops the update when the snapshot fails.
- **Host settings in the backup.** Backups include `/etc/tofi`. A restore on a new server starts with the same settings.
- **One list.** `tofi backups` shows the local and the remote snapshots together.
- **Restore checks the free disk space** before it starts.
- **Restore one account.** `tofi restore --account <id>` restores one account. The other accounts do not change. The runs of that account stop before the restore.
- **Backup alerts.** Admins get a notification when a remote backup fails or when there is no recent good backup, and one more when backups work again. The notification opens the Backups card.

## File storage

- **Move files.** Move the files from the server disk to the bucket, or back to the disk. You can pause, resume and cancel. A move that stops continues from where it stopped. Each file is checked with SHA-256.
- **Reconcile.** A report compares the file records with the bucket. It shows missing files and objects that no record uses. You can delete those objects after a grace period.
- **Change the bucket.** The files in the earlier bucket stay readable. Move them to the new bucket, then retire the earlier bucket. Provider presets fill in the endpoint format for Cloudflare R2, AWS S3, Backblaze B2 and MinIO.

## Interface

- **Side panels as widget cards.** In a wide window, the terminal and the Bot conversation open as cards in the widget column.
- **Mac app title area.** The sidebar is a floating card. When you collapse it, a small capsule stays at the top. In a narrow window, the sidebar opens over the chat. The new position of the window buttons comes with the next Mac app.
- **Default model.** When the organization has no model key and a member did not select a default model, TOFI uses the member's ChatGPT sign-in.
