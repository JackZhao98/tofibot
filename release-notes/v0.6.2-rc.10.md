# TOFI v0.6.2-rc.10

Fixes from live testing of rc.9.

## Fixes

- A task refused because the monthly spend limit is reached now says so and points to Settings › Usage. Before, it said no cause was recorded.
- With a model behind a compatible endpoint (Ollama, for example), the first-run task list no longer says the tasks passed evaluation with that model. It asks you to check that the task was really done.
- When a Bot leaves out a required tool argument, the repair message now lists the values the argument takes. Small local models repair the call more often.
- README: measured times for an install with no cloud account (Ollama on the LAN, no KVM).
