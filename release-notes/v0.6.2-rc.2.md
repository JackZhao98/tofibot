# TOFI v0.6.2-rc.2

## Models

- New provider: OpenAI-compatible server. Use Ollama, LM Studio, vLLM, OpenRouter or another server with an OpenAI-compatible API. Ollama works without a key; the card has an Ollama preset and reads the model list and context size from Ollama.
- First-run setup can connect Ollama or your own server, so you can start without a cloud account.
- A private or LAN model address needs `TOFI_ALLOW_PRIVATE_MODEL_ENDPOINTS=1` on an install with more than one account. TOFI tells you this when it blocks the address.
- The AI Models page and first-run setup say how each provider bills. Costs are on the Usage page.
- OpenAI models (API key or ChatGPT sign-in) can search the web with OpenAI's own search when no other search source (search key, SearXNG or computer) is set. Searches show their sources and are counted on the Usage page.

## Bots

- An empty Bot chat offers three templates: Morning briefing, Inbox digest and Watch a web page. Each makes a schedule that you can see and change.

## Computer

- A computer that is hibernated now gives back its CPU and memory budget when another account's computer must start. Its snapshot stays, and it wakes from the snapshot the next time it is used. (The rc.1 change did not cover this case.)

## Install

- The Compose files map `host.docker.internal`, so the App can reach Ollama on the same host.
