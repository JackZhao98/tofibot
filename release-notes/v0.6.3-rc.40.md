# TOFI v0.6.3-rc.40

The conversation moves further onto the new design, and Devices clears stale errors.

## Chat

- **Messages glide in.** New messages glide up smoothly; no bounce and no extra rise.
- **No cat on the message box.** The cat lives in the header only.
- **Code blocks** have line numbers, syntax colours, copy and folding.
- **Files and pictures** in messages use the new file rows and picture style.
- **Mail drafts** name the fields in your language and carry the Bot's cat on the stamp.
- **Scheduled runs** show a calendar page with the time and the day.
- **Tasks that wait for you** are a bold note with Resume as the main button.

## Devices

- **Stale errors clear.** Replacing or removing the E2B key clears an earlier switch or update failure.
- **No retries against a refused key.** The automatic update waits until the key is replaced.
