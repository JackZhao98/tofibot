# TOFI v0.6.1-rc.2

Changes since v0.6.0. This is a release candidate.

## Browser and desktop

- New browser engine (setting: Browser engine, default Classic). With Playwright, a Bot reads the page as a list of elements with references and acts on them directly. It uses the computer's Chrome, so sign-ins stay. Every action goes through the same review as before.
- New desktop engine (setting: Desktop engine, default Classic). With Accessibility, a Bot reads desktop apps as a tree of controls and clicks or fills them directly. The computer's desktop now runs one shared session bus so the tree covers every app.

## Personal computers (off by default)

- A server can let users connect their own Mac through the desktop app (`TOFI_PERSONAL_COMPUTERS=1`). The Mac decides which Bots and folders are allowed; the admin cannot see these computers.

## Fixes

- A tool call on a personal computer that times out reports that it may have run.
