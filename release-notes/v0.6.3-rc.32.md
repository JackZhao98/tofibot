# TOFI v0.6.3-rc.32

More of the interface moves to the new design kit: message bubbles, Settings pages and the reaction picker.

## Chat

- **Message bubbles use the new kit.** Bubbles from one speaker within five minutes sit closer together, with joined corners. The Bot's name shows above its first bubble in a run.
- **Delivery ticks are gone.** A message that failed to send keeps Edit and Delete in its right-click menu.
- **A reaction picker with eight common reactions.** It replaces the full emoji panel, which makes the app download smaller.

## Settings

- **Buttons and inputs on the new kit** in Models, Connections, Web search, Skills, Permissions, Environments, System and Administration.
- **A pending connection keeps its breathing ring.** The ring is now a state of the new button.
- **Models show official brand marks** for the model providers.
- **Phone-size touch targets stay at 44 px** in the remembered-approvals sheet and the Administration sheets.

## Fixes

- **Long button labels no longer wrap** inside the fixed button height in Settings rows and key forms.
