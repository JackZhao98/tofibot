# TOFI v0.6.3-rc.2

A Bot can now work on your own Mac from the web app. This candidate also has the fixes from live acceptance and from a run of every UI test suite. (v0.6.3-rc.1 was tagged but not published: a release test found the last fix below.)

## New

- Personal Mac. Pair a Mac that runs the TOFI desktop app. A Bot that you chat with on the web can then see the Mac's screen, click, scroll and type (real key codes and key chords such as Cmd+Space), and read the name of the app, window or element under the pointer.
- Every write on a personal Mac goes through the same review as on a Bot computer. The reviewer sees the key chord and the target. System permission prompts on the Mac are left for you to answer. A Mac that stops answering shows as offline.
- Personal computers are on by default. Set `TOFI_PERSONAL_COMPUTERS=0` to turn them off.
- Settings shows the paired Macs.
- Install the web app from the account menu (Install app). On iPhone and iPad, the menu shows how to add it from Safari. There is no service worker, so an update always shows at once.
- Each release publishes the desktop UI artifact, and server-info reports the desktop contract, so the desktop app refuses a server that it does not match.

## Fixes

- An MCP call that you approved now runs when the run continues. Before, the Bot asked for the tool's schema again and the call did not run.
- A Bot can find the schedules and groups that it made. `list_schedules` and `list_groups` are always available, so `update_schedule`, `invite_bot` and `send_group_message` get their ids. Before, the Bot asked you for the id.
- A conversation with unread messages opens at the first unread message.
- An invalid field keeps its red border when you point at it.
- While a reply streams, the chat follows new text at the streaming speed. Before, after some pauses it used the slower arrival speed and trailed the text.
- Dragging in the sidebar is smoother on slow devices. Panels that load in the background no longer restyle the whole page or redraw the whole workspace when they arrive.
- Cat avatars do one style pass per frame together, not one per cat.
- When the run queue started a run at the same moment that another part of the server took it, the queue's copy stopped and marked the running copy's tool calls as interrupted, released its computer and cleared its keys. Now only the copy that owns the run cleans up after it.
