# TOFI v0.6.3-rc.23

Two fixes from the live checks of rc.22.

## Bots

- **The Bot sends what it says it sends.** When a Bot names the files for its reply, only those files go out. Pictures it downloaded to compare or check stay on the Bot computer.
- **Content filter blocks have a name.** When the model provider's content filter blocks a request, the run card says so and offers Retry, in place of "the cause is not known". A request flagged before any output is sent again once, automatically.
