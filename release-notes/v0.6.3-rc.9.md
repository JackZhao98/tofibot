# TOFI v0.6.3-rc.9

Simpler Settings, a movable Bot computer window, screenshots you can ask for, and file storage and backups for administrators.

## New

- **Ask a Bot for a screenshot of your Mac.** When you ask, the Bot puts the screenshot into the chat. A screenshot that the Bot takes only to look at the screen is still not stored.
- **A movable Bot computer window.** Drag the small window anywhere; it snaps to the nearest corner and stays where you put it. Hold ⌥ to place it freely. Computer steps in the chat have a button that opens the window.
- **File storage (administrators).** Administration › Organization resources › File storage stores new attachments in an S3-compatible bucket, such as Cloudflare R2. "Test connection" checks the bucket first. Files you already have stay where they are. A deleted file is kept for 14 days before it is removed.
- **Remote backups (administrators).** Administration has a Backups card that sends encrypted daily backups to a separate bucket. It keeps 7 daily, 4 weekly and 12 monthly backups. You keep the Recovery Key; the server does not store it. An administrator can restore one account from a backup, and undo the restore, without touching the other accounts.
- **Mac app 0.2.3** (built for this release; install it by hand once):
  - Tofi › Check for Updates…; later versions download in the background and ask before they restart.
  - A Bot click on a button presses the button directly when it can, without moving your pointer.
  - The macOS screen-recording prompt is explained before it appears.

## Changed

- **Settings have 8 pages.**
  - Behavior is now a page inside System, with the common settings first and the rest in groups.
  - Tool rules are in Permissions. Web search is in Connections. Bot computer keys are in Environments. Storage is in Usage.
  - Old links still open the right place.
- **Setting names and descriptions no longer name AI models.**
- **Images and mail drafts that a Bot makes now count as Bot output** in storage, not as your uploads. This applies to new files only.

## Fixes

- **Security updates** for two Go libraries (`klauspost/compress`, `golang.org/x/net`).
