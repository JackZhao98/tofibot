# TOFI v0.6.3-rc.37

E2B status and switch errors say what went wrong.

## Devices

- **A revoked E2B key shows as failed.** The E2B row no longer says Ready when E2B refuses the key; it names the reason.
- **A failed switch names the reason.** When moving the home folder fails because of E2B (for example, a key E2B no longer accepts), the page says so.
