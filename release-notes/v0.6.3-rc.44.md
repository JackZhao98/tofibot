# TOFI v0.6.3-rc.44

More pages move onto the new design, and message actions are reworked.

## Messages

- **Message actions sit beside the bubble.** Right-click or long-press a message to open the same menu.
- **A menu opened after Reply stays open** and uses one glass surface.
- **New messages arrive with one smooth glide.** Pressing a key or button stops the arrival motion at once.
- **Faster long chats.** Rows with a task block are memoized again, so arrival is back to 60 ms.

## Settings and pages

- **Connections, Environments and computer settings** use the new banners, checkboxes and icon buttons.
- **System settings** use the new design.
- **Usage** shows a stat reel, a progress meter and a stacked bar.
- **Group settings, New group and Bot secrets** use the new design. The Skills library can list Skills that are off for a Bot.
- **Memory and task execution** use the new cards.
- **Bot computer** uses the new screen panel.

## Mail, tasks and questions

- **Mail read and mail drafts** use the new letter and draft cards.
- **Scheduled runs** show a paused state; the day-one offer and greeting wait use the new parts.
- **Question fields and run-failure actions** use the new design.

## Fixes

- **Bot tool lists stay open** when the page refreshes.
- **Palette rows, the Bot-browser chrome and bottom dialogs** are aligned with the new design.

## Under the hood

- **Old design rules removed** and several flaky UI tests made stable.
