# TOFI v0.6.3-rc.39

The E2B cloud computer updates itself and keeps your files.

## Devices

- **No more Upgrade button.** When a newer computer image is out, the E2B cloud computer is rebuilt from it while it is idle. The home folder is kept; installed software and browser sign-ins come from the new image.
- **You can turn it off.** Devices has the setting Keep the cloud computer up to date (on by default).
- **Updates show on the page.** While it runs, the page says Updating the E2B cloud computer.
