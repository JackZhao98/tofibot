# TOFI v0.6.3-rc.6

User groups and organization resources, a power button for the Bot computer, and fixes.

## New

- **User groups.** On a server with more than one account, an administrator can put accounts into groups. Each group sets four things on their own: AI models, the Bot computer, web search and web fetch. An administrator can also change one capability for one account. Open Settings › Administration › Groups.
- Two groups are built in. **Self-serve** works as before: each person adds their own keys. Every existing account starts in Self-serve, so nothing changes when you update. **Provided** uses the organization's resources.
- **Organization resources.** An administrator adds the keys that the server gives to groups: model providers, an E2B key for cloud computers, and search and fetch services. Open Settings › Administration › Organization resources. These keys are separate from the administrator's own account.
- Organization keys are write-only. After you save a key, nobody can read it back, including administrators. A member never sees an organization key or any part of it. Bots, the Bot computer, run records and exports never get it.
- If the organization has not added a key that a group needs, the member sees a message that says so. TOFI does not use the member's own key in its place.
- **Organization E2B computer.** For a group that gets an E2B computer from the organization, TOFI builds the computer image once for the organization. When a newer image is available, the member can upgrade the computer in Settings › Environments. An upgrade replaces the computer and removes the files on it, so TOFI asks first.
- **Power button for the E2B Bot computer.** The Bot computer window has a power button. Off pauses the computer and keeps its files. A computer that is in use stays on. The idle time before the computer turns off by itself is now a setting (Settings › Behavior, 15 minutes by default).

## Fixes

- When you open a widget on a wide screen, the conversation no longer gets narrow and no empty column appears on the right.
- If you close setup before you have a Bot, TOFI shows the first-use page. Before, it said that it could not open the conversation.
- The examples on the first-use page are now a row of keys that you can click.
- The TOFI logo is sharp again in Safari.
- A button hint no longer changes into the hint of a different button after the list scrolls.
- With models from the organization, setup no longer closes after it makes the first Bot.
- If the organization has not provided a Bot computer, the banner says so and tells you to contact an administrator. Before, it said only that the Bot computer failed to start.
- The proxy settings that the installer prints for Caddy now keep the public host name. Before, every form failed with a security error when TOFI was behind Caddy.
