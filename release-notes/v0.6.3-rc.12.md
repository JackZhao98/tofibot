# TOFI v0.6.3-rc.12

Self-hosted servers answer plain HTTP on the local network, so the Mac app can connect without a certificate.

## Changed

- **Plain HTTP on the local network (self-hosted).** The server's port answers both HTTPS and plain HTTP. Plain HTTP is answered only for addresses on your local network; from the internet the server still needs HTTPS. On the local network you can open `http://<server-ip>:8321` in a browser or in the Mac app, with no certificate warning.
  - New installs have this on. An existing server keeps its setting: to turn it on, set `TOFI_OWNER_ALLOW_LAN_HTTP=1` in `/etc/tofi/tofi.env`, then run `sudo tofi stop && sudo tofi start`.
  - To require HTTPS on the local network too, set it to `0`.

## Fixes

- **Releases are faster.** A release no longer runs every test again; it uses the result of the tests that already ran on the same change.
