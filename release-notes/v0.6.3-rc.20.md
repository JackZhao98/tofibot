# TOFI v0.6.3-rc.20

Folders on a Mac for Bots, the team board replaced by the step list and the Work panel, Bots that try before they say they cannot, page reading on the Bot computer, and a Safari fix for the cats.

## Bots

- **Folders on a Mac.** In the Mac app, go to Settings > Environments > "Folders on this Mac". Select folders and the Bots that can use them. A Bot can read and write files, run commands and use git in those folders, and nowhere else on the Mac. Commands that change something are reviewed. File changes in a granted folder are covered by the grant, unless you set review to include changes. This needs the next Mac app.
- **Bots try before they say they cannot.** A Bot uses what its run has (the Bot computer's shell and tools, the browser, web search, Skills, connected services) before it says that a task is not possible. When it stops, it says what it tried and what is missing.
- **Bots read pages on the Bot computer again.** Since v0.6.2, reading a page in the Bot computer's browser always answered that Chrome was not running, so Bots read pages from screenshots or used another computer. Reading now uses the same Chrome that opens the page.
- **MCP approvals.** "Approve and remember" works from the moment the approval card shows.

## Groups

- **The team board is gone.** In a group, a line under the step list counts the open to-dos and opens the Work panel. In the Work panel you can now change who holds a to-do and filter by goal.

## Interface

- **Cats in Safari.** Moving cats no longer disappear for a frame while a page loads.
