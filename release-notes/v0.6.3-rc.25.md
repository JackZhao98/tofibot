# TOFI v0.6.3-rc.25

One Skill system, and seven new built-in Skills.

## Skills

- **One place for how-tos.** The workflow guides are now built-in Skills: web research, email, web tasks and installing software. A Bot sees the name and one line of each Skill, and reads the full how-to only when the work needs it. You can turn each Skill on or off per Bot. Skills that need a Bot computer do not show for a Bot that has none. The safety rules for web tasks stay in the browser tools, so they apply even when that Skill is off.
- **New built-in Skills.**
  - **pdf**: read, extract tables to a spreadsheet, split, merge, rotate, fill forms, read scanned pages (OCR).
  - **docx-edit**: edit a Word file with tracked changes and comments, or fill a template.
  - **image-edit**: crop, resize, rotate, convert and combine pictures; mark a screenshot with boxes, arrows, numbered labels or blur.
  - **video-edit**: cut, join, compress to a size, make a GIF that fits a size limit, burn subtitles, change audio or speed.
  - **file-convert**: convert between Word, PDF, Markdown, HTML, text, images and archives, and say what a conversion loses.
  - **data-chart**: check a table, compute, and draw a chart whose title states the finding.
  - **web-to-sheet**: turn a table or list on a web page into a spreadsheet, with a Source sheet and a row count.
- **Better spreadsheet and slides Skills.** Recalculation keeps formulas and fails on error cells. Decks get a layout check (off-slide, overlap, leftover template text, empty placeholders) and slide operations.
- Some of these Skills are adapted from Anthropic's open-source skills (Apache-2.0). The license and notices ship with each Skill.
