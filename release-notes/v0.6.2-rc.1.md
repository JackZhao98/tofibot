# TOFI v0.6.2-rc.1

## Computer

- A computer that hibernates when it is idle now gives back its CPU and memory budget. Before, after two accounts used their computers once on a small host, a third account could not start its computer ("concurrent computer resource budget exhausted").
- When the Worker refuses to start a computer, the Bot's tool error now gives the reason.

## Install

- New install path: Docker Compose for a server without KVM (no computer). See `deploy/compose/README.md`. You can add the computer later with the host tool.
- The installer can send an anonymous install report (version, system, architecture, KVM yes/no, result, duration). It is off by default, also with `--yes`. `tofi config telemetry off` turns it off.

## Project

- The README explains the web app license in one paragraph, and has a Releases section. New ROADMAP.md.
