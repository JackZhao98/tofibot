# TOFI v0.6.3-rc.3

Fixes from the first real run of the Mac app.

## New

- The Mac settings page in the desktop app now uses the same settings design and the same seven languages as the web app. It shows the device, what Bots may do, the macOS permissions, the Bots on this Mac, local execution and pairing.
- Settings › Other devices shows a pairing code that you can copy, with a button that opens the Mac settings page where you enter it.

## Fixes

- In the Mac app, the close and shrink buttons of the enlarged Bot computer work again, and so do the image viewer close button and the settings close button in a narrow window. A strip at the top of the window moves the window and used to take those clicks.
- Settings › Bot computer no longer opens a large permission card; it links to the Mac settings page, where the macOS permissions are. When System Settings shows Tofi as on but Tofi still says Not allowed, that page tells you to remove the old entry and add it again, and it can reopen Tofi, which macOS needs before Screen Recording applies.
- The Bot computer status says what the computer is doing: asleep (it wakes when a Bot needs it), waking, failed to start (with Try again), or unavailable. Before, most of these read "Waiting for the Bot computer".
